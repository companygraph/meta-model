# A graph written the way beacon writes one

A trimmed copy of the pages of beacon's own instance: the singular pages, the tasks bounded context with its aggregates, concept designs and events, one role, one risk and the sources they cite, with each type's folder README. It is what `verify/consumer.test.mjs` holds to R1 through R18, against the core and the software pack of the tarball the test installs, so it carries no `meta/` of its own. It is a fixture and not the instance, which is mastered in beacon-build/beacon-model.
