# An agent posts an entry

> An entry becomes part of the books without a person having decided it.

## Cause

The agent reaches the accounting system with a tool or a user that can post, or acts under a person's credentials.

## Consequence

The books carry an entry nobody with the duty to keep them decided, the audit trail is wrong, and reversing it takes another entry.
