# Product Engineer

> Builds product features from inside Product, to engineering's standard.

## Responsibilities

- Builds each feature to the customer need it answers.
- Keeps each change small enough to be reviewed in one sitting, with the tests that show it.
- Holds each change to the engineering standard, whatever Product asks.
