# Product Discovery

> Finding out what is worth building before building it.

## In practice

Talk to the people who would use a thing before the first line of it is written. Frame the question so that the answer can be no, and hear it when it is. Test the cheapest version of an idea that could still turn out wrong, and stop when it does.
