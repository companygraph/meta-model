# Service

> Software Beacon builds and runs itself, deployed to its own cluster.

## What it means

Opened by nobody directly: the products are the faces people see, and a service stands behind them, built by Beacon's engineers and run on the Beacon cluster.

Software a vendor runs for Beacon is SaaS; what services run on is Platform.
