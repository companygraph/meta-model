# SaaS

> Software a vendor runs for Beacon, reached over the internet and paid for by use.

## What it means

The vendor runs it, Beacon connects to it, and where it handles personal data the vendor is a data processor named on the page.

Software Beacon runs itself is Service, whatever it does.
