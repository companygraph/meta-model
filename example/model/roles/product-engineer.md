# Product Engineer

> The seat that builds product features from inside Product, to engineering's standard.

## What it takes

A feature described by the customer need it answers, and the engineering standard the change is held to.

## What it produces

A feature that does what the need asks, in a change small enough to be reviewed in one sitting, with the tests that show it.

## What it never does

- Never merges its own change.
- Never ships a change the engineering standard would refuse because Product asked for it.
- Never builds a feature without the customer need it answers.
