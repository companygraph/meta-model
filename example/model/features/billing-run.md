# Billing run

> A finance team can close a billing period and have every invoice for it issued at once, the same whoever runs it.

## Description

Closing a period applies every contract’s rules to the usage recorded in it and issues one invoice per customer, and running it twice on the same inputs issues the same invoices. It ends when the invoices are issued. Sending reminders and collecting payment come after it and are not part of it.
