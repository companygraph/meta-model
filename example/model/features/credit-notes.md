# Credit notes

> A finance team can correct an invoice already sent, and the payer can read what changed and why.

## Description

A credit note is issued against an invoice when the usage it read or the rule it applied turns out wrong, and it is computed from the corrected usage or the corrected rule, so every line on it explains itself the way an invoice line does. It never changes the invoice it corrects, and it carries no amount typed in by hand.
