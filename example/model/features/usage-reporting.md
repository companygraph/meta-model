# Usage reporting

> Usage can be reported by the systems that see it happen, as it happens, so nobody types it in at the end of the month.

## Description

Each report becomes a usage record under the contract it counts against, kept as it was sent. It records and does not correct: a report sent wrong is answered by a second report that offsets it, never by editing the first, so what a billing run read can always be read again.
