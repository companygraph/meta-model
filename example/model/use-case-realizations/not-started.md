# Not started

> At least one step of the main success scenario is not built yet.

## What it means

A use case is Not started while some step of its main success scenario has no code behind it, and its page needs no `## Evidence`. A page enters the level when the use case is written and leaves it when the last step of the main success scenario is built and a row that satisfies it is added. While a use case is Not started, a reader may not rely on the primary actor reaching the goal.
