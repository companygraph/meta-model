# Built

> The requirement is built, and no test yet observes what its fit criterion observes.

## What it means

A requirement is Built when the product has the code that meets it and the page shows where, in at least one `## Evidence` row. A page enters the level when that row is added, moves up to Verified when a test observes the fit criterion, and moves down to Not started when the code is removed. While a requirement is Built, a reader may rely on the behavior being there and not on its staying so, because nothing yet fails when it stops.
